# Дизайн-система сайта wan flo1d's store

Справка по тому, что реально используется в коде: шрифты, цвета, анимации, отступы и повторяющиеся приёмы. Составлено по факту (grep по `app/page.tsx`, `app/components/*.tsx`, `app/globals.css`), включая то, что не используется, но лежит в коде.

## Что это за сайт и какая у него задача

Личный портфолио-лендинг разработчика **wan flo1d** (Максим) — визитка фрилансера/инди-разработчика, а не блог и не продукт. Это **продающая страница одного экрана** (one-pager) с прокруткой по секциям, построенная как редакторское "досье" с нумерованными главами: работы → результат, который это даёт → почему работать именно со мной → услуги и цены → навыки → доп. работы → отзывы.

Задача сайта — **конвертировать посетителя в клиента в Telegram**. Почти все CTA на странице ведут на `t.me/wanflo1dceo`.

### Стек

- **Next.js 16** (Turbopack) + **React 19** + TypeScript
- **Tailwind CSS v4** — вся вёрстка только утилити-классами + CSS-first тема (`@theme inline` в `globals.css`)
- **Framer Motion** — все анимации (детали ниже)
- **Lenis** — плавный инерционный скролл поверх нативного
- `lucide-react` + `react-icons` — иконки
- Данные (работы, услуги, навыки, отзывы) — **хардкод прямо в коде**, в объекте `translations` (en/ru) внутри `app/page.tsx`. Никакой CMS/базы нет — новый проект в портфолио добавляется правкой кода.

### Структура страницы (по порядку скролла)

1. **Intro-заставка** (3–4 сек при первой загрузке) — анимация смены лого `WHYSPACY → WAN FLO1D`
2. **Hero** — заголовок, подпись, фото, соцсети
3. **Бегущая строка клиентов/компаний**
4. **01 — Projects** — сетка кейсов (десктопные `16:9` + отдельная горизонтальная лента для мобильных/Telegram-скриншотов `9:19`), клик → модалка с полной галереей без обрезки и мини-кейсом (тип проекта / роль / результат)
5. **02 — Results** — 4 коротких статемента о том, что сайт даёт любому бренду в принципе (доступность 24/7, доверие, удобство, отличие от конкурентов) — универсальная ценностная подача, не статистика по собственным проектам
6. **03 — Why Me** — большой editorial-стейтмент + 5 коротких реальных аргументов (без карточек, без выдуманных фактов)
7. **04 — Services** — список услуг с ценами, построен как редакторский список строк, не карточки
8. **Contact** — чёрный блок-CTA (Telegram/Instagram/Email) внутри секции услуг
9. **05 — Skills** — категории навыков, статичные (без анимации — см. "Анимации")
10. **06 — Other works** — горизонтальный scroll-ряд, сейчас **заглушка** с примерными карточками (реальных доп. проектов пока не добавлено)
11. **07 — Reviews** — "стена цитат" (masonry через CSS columns)
12. Footer

Навигация: вертикальный scroll-spy сайдбар на десктопе (lg+, компонент `SideRail`) и гамбургер-меню на мобильных/планшетах — оба используют одну и ту же нумерацию глав (00–07), что и призрачные цифры на самих секциях.

### Честно слабые места

- "Other works" — заглушка, не реальный контент.
- Все данные в коде, без админки — любое обновление требует правки `page.tsx` руками.
- Несколько старых `useState`/`useEffect` в `page.tsx` не используются (мелкий технический долг, не трогал).
- Нет визуальной QA в браузере в этой среде — все правки проверяются только через `tsc`/`eslint`/`next build`.

## Шрифты

| Где | Шрифт | Как подключен |
|---|---|---|
| Заголовки, крупные цифры, цены, акцентный текст | **Benzin** (self-hosted, `/public/fonts/`) | через `@font-face` + класс `.font-display` (генерируется Tailwind'ом из темы, см. ниже) |
| Основной текст (`body`, описания, лейблы без `.font-display`) | **Golos Text** (Google Font, Cyrillic + Latin) | через `next/font/google` в `app/layout.tsx`, переменная `--font-golos` |

Начертания Benzin: Regular (400), Medium (500), Semibold (600), Bold (700), ExtraBold (800) — **900 не существует**. Правило в коде: класс `.font-display` (только меняет `font-family`) всегда идёт в паре с явным Tailwind-весом — `font-extrabold` (800, реальный самый жирный) для заголовков, `font-semibold` (600, реальный) для более лёгких display-лейблов (меню, бегущая строка компаний). `font-black` (900) больше не используется нигде рядом с Benzin.

Как это устроено технически:
```css
@theme inline {
  --font-sans: var(--font-golos), Arial, Helvetica, sans-serif;
  --font-display: "Benzin", var(--font-golos), Arial, Helvetica, sans-serif;
}
```
Tailwind v4 сам генерирует `font-sans`/`font-display` утилиты из `--font-*` токенов темы — отдельный самодельный класс `.font-display` **не нужен и не существует** (раньше была дублирующаяся дефиниция с коллизией имён, сейчас убрана). На крупных заголовках `font-display` почти всегда идёт с `tracking-tight` (чуть сжатый трекинг для display-типографики).

Golos Text подключён через `next/font/google` (не руками через `@font-face`) — self-hosted Next.js'ом при сборке, с `subsets: ["latin", "cyrillic"]`, веса 400/500/600.

Старый баг устранён: раньше в `globals.css` было два конфликтующих правила `body { font-family }`, из-за чего Benzin никогда не применялся как основной шрифт текста. Сейчас правило одно: `font-family: var(--font-sans)` на `html, body`.

## Цвета

Палитра в основе монохромная (чёрный/белый/оттенки серого через opacity), **плюс один дозированный акцентный цвет** — часть идентичности бренда, не заливка.

### Базовые значения

| Токен | Значение | Где |
|---|---|---|
| Фон сайта | `--color-background: #f7f7f5` (тёплый off-white) | `body`, fade-маски scroll-лент |
| Текст по умолчанию | `--color-foreground` / `text-black` | везде |
| **Accent** | `--color-accent: #ff5a1f` (flame orange), hover/dark-вариант `--color-accent-dark: #d9470f` | см. ниже — только точечно |
| Инверсия | `black` / `white` | CTA-кнопки, контактный блок, лайтбокс |

### Где используется accent (и больше нигде)

Правило брифа — "дозированно, не заливками" — выдержано буквально:
- Активный пункт в `SideRail` (цифра + индикатор-полоска)
- Кнопка "Contact" в сайдбаре (единственная акцентная CTA на сайте, всегда на виду)
- Цена на карточке проекта (`text-accent`, в гриде и на мобильной ленте)
- Цена в модалке проекта (на чёрной плашке)
- Маленькая цифра-индекс рядом с лейблом секции (`SectionHeading`)
- Короткие заголовки-статементы в блоке Results
- CTA-стрелка в строке услуги (`Order Service`) при hover

Больше нигде — ни фонов, ни бордеров, ни крупных заливок.

### Чёрный и белый с прозрачностью

Это основной инструмент построения иерархии — не разные цвета, а разная *прозрачность* одного чёрного/белого.

- `/10` — бордеры и разделители
- `/35–/50` — вспомогательный текст, лейблы, цифры
- `/60–/75` — основной читаемый текст второго уровня (описания)
- `/80–100` (чёрный сплошной) — заголовки, акцентный текст
- `/[0.03]–/[0.05]` — чисто декоративные водяные знаки (цифры глав, шум)

### Фоновый шум (grain)

`opacity-[0.03] mix-blend-multiply` + SVG-текстура — фикс-слой на весь вьюпорт, едва заметная зернистость поверх фона.

## Радиус (скругления) — теперь осмысленно разный, не один на всё

- `rounded-full` — только пилюли, CTA-кнопки, маленькие теги/badges
- `rounded-md` (6px) — обычные контентные карточки (сетка проектов, тикеты "доп. работ") — осознанно **уменьшено** с прежних 22–24px, чтобы карточки не выглядели как типовой SaaS-конструктор
- `rounded-[24–42px]` — только по-настоящему крупные блоки (модалка проекта, чёрный контактный блок) — чем крупнее блок, тем больше можно оставить скругление
- Редакторские списки (Services, Skills, Results-метрики) — **без скруглений вовсе**, только `border-b`/`border-t` разделители — это сознательный brutalist-акцент, а не недосмотр

## Анимации (после аудита)

Раньше на сайте одновременно жили: intro, scroll-reveal с разных сторон, stagger, marquee компаний, бесконечные бегущие строки навыков, hover-трансформы, курсор-блоб, zoom фото, модалки, Lenis. Сделан аудит — часть убрана или уменьшена.

**Убрано целиком:**
- Курсор-блоб (`useMotionValue`/`useSpring`, пятно, следящее за мышью) — чисто декоративное, не помогало ни пониманию интерфейса, ни направлению внимания. Удалено вместе с мёртвым кодом.
- Бегущая строка навыков (`skills`) — заменена на статичный wrap-список. Движущийся текст плохо читается, а это список реальных навыков, который клиент должен быстро просканировать, а не разглядывать в движении.
- Разнонаправленные слайды заголовков секций (`SectionHeading` раньше летел то слева, то справа по секциям) — теперь всегда одинаковый спокойный fade + `y: 14px`.

**Осталось, но короче/спокойнее:**
- Scroll-reveal (`whileInView`): дистанция уменьшена (`y: 10–24px`, было 30–80px), длительность — `0.35–0.5s` (было 0.5–0.8s), стаггер-delay — `0.04–0.06` (было 0.06–0.08).
- Hero-анимация при загрузке (`animate`, не scroll-triggered) — тоже сокращена (`y: 24px` вместо 80px, `scale: 0.97` вместо 0.9).

**Оставлено как оправданное (проходит правило "помогает/направляет/создаёт качество/облегчает переход"):**
- Лента компаний (`marquee`, `x: ["0%","-50%"]`, 24s linear) — низкий тон, не конкурирует за внимание, стандартный "trusted by"-приём.
- Hover-микроинтерактивность: `-translate-y-1.5` на карточках, стрелки `ArrowUpRight` "улетают" в сторону клика, zoom фото `scale-[1.04–1.06]` — всё это сигналит кликабельность, не декор ради декора.
- `AnimatePresence` + fade/scale на модалке и лайтбоксе — помогает переходу между состояниями (open/close), это буквально правило №4.
- Lenis — не анимация элемента, а физика скролла страницы целиком; низкая стоимость, ощущение качества.
- Intro-заставка — одноразовая, не повторяется при скролле, задаёт тон бренду один раз при первом визите.

## Повторяющиеся UI-приёмы

- **"Нумерация глав"** — у каждой крупной секции призрачная огромная цифра (00…07) через компонент `SectionHeading`, плюс та же цифра дублируется в сайдбаре (`SideRail`) и в выпадающем мобильном меню — сквозная идея, которая держит разнородные блоки сайта визуально вместе.
- **Разделители вместо рамок** там, где раньше были карточки (Services, Skills, Results) — `border-b`/`border-t border-black/10`, построено как список, а не грид.
- **`tabular-nums`** почти везде, где есть цифры (цены, счётчики `01/07`) — чтобы цифры не "прыгали" по ширине при смене.
- **backdrop-blur** используется умеренно и только там, где реально есть прозрачность поверх контента (сайдбар/мобильный хедер, пилюли-теги, модалки) — не на статичных блоках со сплошным фоном.
- **Results — универсальная ценностная подача, не самостатистика**: 4 коротких статемента о том, что сайт даёт любому бренду (24/7, доверие, доступность, отличие от конкурентов), без цифр и без завязки на собственные проекты.

## Что было почищено в этом проходе

- Два конфликтующих правила `body { font-family }` — исправлено, осталось одно.
- Коллизия имён между Tailwind-авто-утилитой `.font-display` (из темы) и самодельным классом `.font-display` — самодельный убран, остался только авто-сгенерированный.
- `.vinyl-*` CSS (~120 строк, неиспользуемый код от старой концепции с пластинкой) — удалён.
- `@keyframes intro-blink` (объявлен, не применялся) — удалён.
- `--background`/`--foreground` + dark-mode media query (заготовка от create-next-app, не влияла на реальную отрисовку) — удалена, фон теперь явный токен темы.
- Курсор-блоб и связанный с ним код (`useMotionValue`, `useSpring`, `mousemove`-листенер) — удалён целиком.
